# LP — Linguagens de Programação

`LP` significa **Linguagens de Programação**. Esta área reúne cursos independentes, organizados para sair do zero e chegar à prática profissional.

## O que é uma linguagem de programação?

É uma forma estruturada de escrever instruções que um computador consegue executar. Cada linguagem tem regras próprias, mas todas são usadas para transformar um problema em passos claros: receber dados, processá-los e mostrar ou guardar um resultado.

## Como usar os cursos

1. Comece pelo `README` da linguagem escolhida.
2. Siga os módulos na ordem; os nomes numerados mostram a sequência pedagógica.
3. Digite e execute os exemplos em vez de apenas ler.
4. Faça os exercícios antes de abrir a solução.
5. Use os projetos para juntar o que aprendeu.

Não tente decorar tudo. O objetivo é entender, praticar e aprender a consultar documentação quando necessário.
