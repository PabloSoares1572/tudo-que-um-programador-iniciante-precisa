# 27 — Python profissional

> ⚫ **Profissional/Especialista**

Conhecer sintaxe é começo. Um projeto profissional pode ser entendido, instalado, testado, operado e alterado por outras pessoas.

## Checklist de projeto

\`\`\`text
README → ambiente → dependências → configuração → código organizado
→ testes → lint/format → logging → segurança → CI → deploy/monitoramento
\`\`\`

## Competências

- decompor requisitos em tarefas pequenas;
- usar Git e revisar mudanças;
- comunicar limites, riscos e dúvidas;
- escrever testes para regras relevantes;
- investigar bug com evidência;
- manter dependências/configuração;
- documentar decisão e operação;
- aprender documentação de ferramentas novas sozinho.
