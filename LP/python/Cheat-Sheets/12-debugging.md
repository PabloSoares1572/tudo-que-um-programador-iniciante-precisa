# Debugging

\`\`\`text
Sintoma → reproduzir → reduzir → hipótese
→ inspecionar valores/tipos → testar mudança → confirmar → teste de regressão
\`\`\`

- traceback: leia última linha primeiro;
- breakpoint: pause antes da linha suspeita;
- \`print\`: temporário, com contexto;
- logging: produção/fluxos difíceis;
- teste: impede bug de voltar.
