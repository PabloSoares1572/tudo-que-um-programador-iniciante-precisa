# Git

\`\`\`text
git init
git status
git add arquivo.py
git commit -m "mensagem clara"
git switch -c minha-branch
git diff
git log --oneline
\`\`\`

- Commit pequeno e descritivo.
- Revise \`git diff\` antes de commitar.
- Nunca suba \`.env\`, tokens ou arquivos grandes sem decisão.
- Branch isola mudança; PR permite revisão.
