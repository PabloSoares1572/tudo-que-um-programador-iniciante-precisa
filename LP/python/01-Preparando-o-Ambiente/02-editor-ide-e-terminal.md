# Editor, IDE e terminal

## Editor x IDE

Um **editor de código** escreve arquivos de texto com recursos como destaque de sintaxe. Uma **IDE** reúne edição, execução, depuração, navegação de projeto e outras ferramentas. Você pode aprender em qualquer opção confiável; a base é a mesma.

Opções conhecidas incluem VS Code, PyCharm, IDLE e editores simples. Escolha uma que consiga abrir uma pasta e mostrar o terminal integrado, mas não fique trocando de ferramenta toda semana.

## O que é o terminal?

É uma interface textual para executar comandos. No Windows você pode usar PowerShell; em Linux/macOS, um shell no terminal. O terminal não é “coisa de hacker”: ele permite executar Python, instalar dependências do projeto e usar Git com precisão.

## Comandos seguros para se orientar

```text
Windows PowerShell: Get-Location
Linux/macOS: pwd
```

Eles mostram a pasta atual. Antes de criar ou apagar qualquer coisa, saiba em qual pasta você está.

## Configuração mínima do editor

- abra a pasta inteira do projeto, não arquivos soltos;
- selecione o interpretador Python correto;
- habilite formatação/lint somente depois de entender as mensagens;
- use breakpoints quando chegar ao módulo de debugging;
- nunca cole extensões ou scripts de origem desconhecida só porque “arrumam tudo”.
