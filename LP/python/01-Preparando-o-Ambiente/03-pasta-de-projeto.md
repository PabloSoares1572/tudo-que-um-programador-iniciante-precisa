# Criando uma pasta de projeto

Crie uma pasta para cada projeto. Dentro dela, comece com um arquivo `main.py`:

```text
meu-primeiro-projeto/
└── main.py
```

Execute a partir dessa pasta:

```text
Windows: py main.py
Linux/macOS: python3 main.py
```

O sufixo `.py` identifica um arquivo de código Python. Evite nomes como `random.py`, `json.py` ou `pytest.py`, pois podem esconder módulos reais da biblioteca/pacotes.

## Atividade

Crie `meu-primeiro-projeto/main.py`, deixe-o vazio, execute e observe que Python aceita um arquivo vazio sem mostrar saída. Em seguida, avance para o próximo módulo e acrescente seu primeiro `print`.
