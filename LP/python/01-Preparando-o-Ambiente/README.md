# 01 — Preparando o ambiente

> 🟢 **Iniciante** — faça esta etapa antes de criar projetos.

Você precisa de três coisas: o **interpretador Python**, um lugar para editar texto e um **terminal** para executar comandos. Editor e IDE são ferramentas; não são a linguagem em si.

## Índice

1. [Instalação e verificação](./01-instalacao-e-verificacao.md)
2. [Editor, IDE e terminal](./02-editor-ide-e-terminal.md)
3. [Pasta de projeto e execução](./03-pasta-de-projeto.md)

## Objetivo

No final, você deve conseguir abrir uma pasta, criar `main.py`, executá-lo e descobrir qual interpretador está sendo usado.

## Segurança e organização

Não execute instaladores desconhecidos ou “packs de Python”. Baixe do site oficial ou use o gerenciador oficial da sua distribuição. Em projetos com pacotes externos, use ambiente virtual — assunto aprofundado no módulo 18.
