# Checkpoint — Python intermediário

Você deve conseguir:

- [ ] organizar código em módulos;
- [ ] ler/gravar JSON/CSV com encoding;
- [ ] tratar exceções específicas;
- [ ] explicar classe, objeto, composição e dataclass;
- [ ] usar comprehensions sem perder legibilidade;
- [ ] criar ambiente virtual e instalar pacote no lugar certo;
- [ ] escrever teste pytest para comportamento e erro;
- [ ] investigar bug com breakpoint, log ou teste.

## Mini projeto

Evolua uma lista de tarefas CLI: módulos separados, JSON, validação, testes, arquivo gitignore, README e pelo menos três commits descritivos.

## Autoavaliação

Explique por que uma função de regra de negócio não deveria chamar input nem gravar arquivo diretamente. Se não conseguir, pratique separação de responsabilidades.
