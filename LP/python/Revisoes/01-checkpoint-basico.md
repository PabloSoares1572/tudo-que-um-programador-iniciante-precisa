# Checkpoint — Python básico

Você deve estar confortável antes de avançar se consegue:

- [ ] criar/executar arquivo Python;
- [ ] explicar variável, tipo, entrada e saída;
- [ ] converter input corretamente;
- [ ] usar operadores, condições e loops;
- [ ] manipular lista, dicionário, set e tupla;
- [ ] criar função com parâmetros e retorno;
- [ ] ler um traceback de ValueError, TypeError e NameError.

## Revisão prática

Crie programa de notas que recebe alunos, calcula média, valida intervalo 0–10, classifica situação e lista resultado. Primeiro faça em um arquivo; depois extraia funções.

## Perguntas

1. Por que input não devolve número?
2. Quando usar for e quando usar while?
3. Por que não usar except sem tipo?
4. Qual estrutura escolheria para produto por ID? Por quê?

Se alguma resposta ficar confusa, retorne ao módulo correspondente antes de avançar.
