# Checkpoint — Python profissional

Você está preparado para especializar quando consegue:

- [ ] definir contrato de módulo/API;
- [ ] usar banco com query parametrizada e transação consciente;
- [ ] configurar ambiente sem segredos hardcoded;
- [ ] escrever teste unitário e integração apropriados;
- [ ] documentar execução, configuração e limites;
- [ ] interpretar logs e erro sem expor dados;
- [ ] justificar estrutura, dependência e otimização com evidência;
- [ ] usar Git/PR para mudança pequena e revisável;
- [ ] aplicar checklist de segurança antes de publicar.

## Projeto de consolidação

Escolha uma trilha e entregue uma versão pequena, completa e documentada. Deve existir problema claro, escopo limitado, testes, README, dados de exemplo seguros e lista honesta de limitações.

Não espere dominar tudo para buscar especialização. A habilidade profissional é aprender com autonomia, validar informação e evoluir projeto com segurança.
