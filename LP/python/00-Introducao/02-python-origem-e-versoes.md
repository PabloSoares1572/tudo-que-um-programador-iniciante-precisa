# O que é Python, CPython e versões

## História resumida

Python foi criado por Guido van Rossum e lançado no início dos anos 1990. A linguagem valoriza legibilidade, produtividade e uma biblioteca padrão ampla. Sua filosofia é associada ao texto “The Zen of Python”, disponível ao executar `import this` no interpretador.

## Características importantes

- sintaxe baseada em indentação;
- tipagem dinâmica: o tipo está ligado ao valor em tempo de execução;
- multiparadigma: programação procedural, orientada a objetos e funcional em diferentes graus;
- multiplataforma: Windows, Linux e macOS;
- grande ecossistema de bibliotecas.

## Python, CPython e outras implementações

**Python** é a linguagem e sua especificação. **CPython** é a implementação de referência, escrita principalmente em C e a mais usada. Existem outras implementações, mas este curso usa CPython porque é o padrão do ecossistema e da documentação comum.

## Python 2 x Python 3

Python 2 é histórico e não deve ser usado em projetos novos. Este curso usa **Python 3 moderno e suportado**. Na revisão deste material, a documentação oficial está na linha 3.14; prefira a versão suportada mais recente compatível com suas ferramentas e projeto.

> Não copie tutorial antigo só porque aparece primeiro numa busca. Confirme se ele diz explicitamente Python 3 e se a sintaxe ainda é atual.

## Onde Python é usado?

Automação, APIs, backend web, ferramentas de linha de comando, testes, dados, IA, scripts de infraestrutura e educação. A linguagem não decide a carreira por você: os projetos e fundamentos que você constrói importam mais.

## Exercício de observação

Abra um terminal após instalar Python e execute:

```text
python --version
```

No Windows, o comando recomendado pode ser `py --version`; em Linux/macOS costuma ser `python3 --version`.
