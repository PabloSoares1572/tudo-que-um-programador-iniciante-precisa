# 00 — Introdução à programação

> 🟢 **Iniciante** — não exige conhecimento prévio.

Antes de aprender comandos, você precisa entender o que está fazendo quando programa. Programação é usar uma linguagem com regras precisas para escrever instruções que resolvem um problema.

## Ideia central: entrada → processamento → saída

Um programa normalmente recebe alguma **entrada**, transforma os dados e produz uma **saída**.

```text
idade informada → comparar com 18 → mostrar "maior de idade" ou "menor de idade"
```

Esse raciocínio aparecerá no curso inteiro, desde uma calculadora até uma API.
