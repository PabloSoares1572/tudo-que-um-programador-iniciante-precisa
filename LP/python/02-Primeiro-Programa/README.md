# 02 — Primeiro programa e sintaxe

> 🟢 **Iniciante**

Crie `main.py` com o conteúdo abaixo:

```python
print("Olá, mundo!")
```

Execute com `py main.py` no Windows ou `python3 main.py` em Linux/macOS.

## Linha por linha

- `print` é uma função embutida que mostra algo na saída.
- `(` e `)` delimitam os argumentos enviados à função.
- `"Olá, mundo!"` é uma **string**, ou seja, texto.
- as aspas são necessárias para diferenciar texto do nome de uma variável.

## Resultado esperado

```text
Olá, mundo!
```

## O que acontece se eu remover as aspas?

```text
print(Olá, mundo!)
```

Isso não é texto válido para Python; o interpretador mostrará um erro de sintaxe. Erros são parte do aprendizado: leia a linha indicada e corrija uma coisa por vez.
