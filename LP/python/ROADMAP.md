# Roadmap — Python do zero ao profissional

```text
NUNCA PROGRAMEI
      ↓
Lógica e algoritmos
      ↓
Python básico: variáveis, entrada e saída
      ↓
Condicionais e loops
      ↓
Estruturas de dados e funções
      ↓
Arquivos, módulos e tratamento de erros
      ↓
POO e Python intermediário
      ↓
Testes + debugging + Git + ambientes virtuais
      ↓
Banco de dados + APIs + automação
      ↓
Python avançado e performance
      ↓
Projetos reais, segurança e práticas profissionais
      ↓
Especialização
```

## O que dominar em cada fase

| Fase | Você deve conseguir fazer antes de seguir |
| --- | --- |
| Base | Explicar entrada, processamento e saída; executar um arquivo `.py`; ler um erro simples |
| Controle de fluxo | Resolver problemas usando `if`, `for` e `while` sem copiar estrutura pronta |
| Dados e funções | Escolher entre lista, dicionário, conjunto e tupla; dividir uma tarefa em funções pequenas |
| Organização | Importar módulos, trabalhar com arquivos, tratar erros específicos e organizar pastas |
| Intermediário | Usar comprehensions com clareza, iterar corretamente, entender objetos e escrever tipos básicos |
| Qualidade | Criar testes, usar breakpoints, Git, `.gitignore`, `venv` e dependências reproduzíveis |
| Aplicações | Persistir dados, consumir/criar APIs, validar entradas e registrar logs |
| Profissional | Projetar módulos coesos, documentar, revisar segurança e escolher especialização conscientemente |

## Ritmo recomendado

Para quem trabalha ou estuda, 30 a 60 minutos de prática em dias regulares é melhor do que uma maratona rara. Em cada sessão:

1. reveja 5 minutos do assunto anterior;
2. leia e execute um exemplo pequeno;
3. resolva uma atividade sem olhar a resposta;
4. anote a dúvida e pesquise pela mensagem de erro ou pela documentação.
