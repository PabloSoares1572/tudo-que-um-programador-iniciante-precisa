# 07 — Estruturas de dados

> 🟢 **Iniciante → 🟡 Intermediário**

Estruturas de dados organizam valores. A escolha muda a clareza, o desempenho e o conjunto de operações disponíveis.

| Estrutura | Use quando | Característica central |
| --- | --- | --- |
| `list` | ordem e itens repetidos importam | mutável, acessada por índice |
| `tuple` | sequência não deve mudar | imutável |
| `dict` | você busca por uma chave | mapeia chave → valor |
| `set` | itens únicos e operações de conjunto | sem ordem de uso como regra de negócio |
