# 14 — Python avançado

> 🔴 **Avançado**

Este módulo apresenta recursos úteis para ler bibliotecas e resolver casos especializados. Não é uma lista de itens para usar em todo projeto. Código profissional também é saber **não** usar a ferramenta mais complexa.

## Assuntos

- [Data model e métodos especiais](./01-data-model-e-dunder.md)
- [Memória, garbage collection, GIL e CPython](./02-cpython-memoria-e-gil.md)
- introspecção com `type`, `isinstance`, `dir`, `getattr` e `inspect`;
- descriptors e properties avançadas;
- context managers e iteradores customizados;
- decorators parametrizados;
- metaclasses: conhecimento de leitura e casos raros.

## Prioridade prática

No dia a dia, dunder methods, context managers, generators, decorators bem feitos e `dataclass` aparecem mais do que metaclasses. Aprenda a ler os conceitos mais raros; não tente encaixá-los em um projeto simples.
