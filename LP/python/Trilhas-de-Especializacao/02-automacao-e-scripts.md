# Trilha — Python para automação e scripts

## Pré-requisitos

Arquivos, pathlib, CSV/JSON, exceções, logging, terminal, Git e ambiente virtual.

## Ordem

1. Processar arquivo de teste.
2. Criar modo simulação e logs.
3. Automatizar CSV/planilha local.
4. Consumir API autorizada.
5. Criar CLI com argumentos e configuração.
6. Agendar/operar com segurança.

## Projetos

- organizador seguro;
- relatório de CSV;
- consolidador de arquivos;
- verificador de API com alertas permitidos.

Nunca automatize spam, violação de termos, exclusão em massa sem proteção ou comandos construídos com entrada externa.
