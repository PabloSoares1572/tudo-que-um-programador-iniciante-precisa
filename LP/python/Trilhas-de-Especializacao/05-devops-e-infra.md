# Trilha — Python para DevOps e infraestrutura

## Pré-requisitos

Terminal Linux/Windows, Python básico, arquivos, rede/HTTP, Git, ambientes virtuais, logs e segurança.

## Ordem

1. CLI e configuração por ambiente.
2. APIs de infraestrutura autorizadas.
3. Logs, métricas e alertas.
4. Testes e CI.
5. Contêineres e deploy.
6. Princípio de menor privilégio e gestão de segredos.

## Projetos

- CLI que verifica configuração;
- relatório de inventário a partir de dados de teste;
- ferramenta que consulta endpoint de saúde;
- automação com dry-run e logs.

Nunca rode automação em infraestrutura real sem autorização, ambiente de teste e plano de rollback.
