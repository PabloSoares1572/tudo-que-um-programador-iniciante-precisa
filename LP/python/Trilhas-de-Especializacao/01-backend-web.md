# Trilha — Python para backend web

## Pré-requisitos

Funções, POO básica, módulos, ambientes virtuais, HTTP, banco SQL, testes e Git.

## Ordem

1. HTTP, JSON, status codes e validação.
2. FastAPI, Django ou Flask — escolha um.
3. Banco e migrações.
4. Autenticação/autorização segura.
5. Testes de rotas e regras.
6. Logs, configuração, deploy e observabilidade.

## Projetos

- API de tarefas;
- catálogo com busca/paginação;
- aplicação de agenda;
- projeto final com banco e documentação.

## Tecnologias para pesquisar depois

Framework escolhido, PostgreSQL, migrações, ORM com SQL consciente, Docker e CI. Não comece por microserviços ou Kubernetes sem ter mantido um monólito pequeno.
