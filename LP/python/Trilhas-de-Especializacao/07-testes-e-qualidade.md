# Trilha — Python para testes e qualidade

## Pré-requisitos

Funções, POO básica, erros, ambientes virtuais, Git e leitura de código.

## Ordem

1. pytest e assertions.
2. fixtures e dados de teste.
3. mocks para bordas externas.
4. integração e banco temporário.
5. cobertura e mutação de código como sinais, não metas isoladas.
6. lint, formatter, tipos e CI.

## Projetos

- adicionar testes a projeto antigo;
- reproduzir bug como teste;
- criar biblioteca pequena com documentação e CI;
- revisar uma PR simulada com checklist de qualidade.
