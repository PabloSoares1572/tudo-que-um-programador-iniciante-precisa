# Trilha — Python para Machine Learning e IA

## Pré-requisitos

Python, funções, estruturas, ambientes, arquivos, SQL/estatística básica e pensamento crítico sobre dados. Não comece por framework de IA sem conseguir validar uma tabela ou explicar treino/teste.

## Ordem

1. Dados, estatística e visualização.
2. NumPy/pandas ou ferramentas equivalentes.
3. Regressão/classificação e métricas.
4. Separação treino/validação/teste.
5. Reprodutibilidade, versionamento de dados/modelos.
6. Deploy, monitoramento e avaliação de risco.

## Projetos

- classificador em dados públicos/fictícios;
- análise de métricas;
- API de inferência simples;
- relatório de limitações e vieses.

Use a área [IA](../../../IA/README.md) deste repositório para aprender uso responsável de ferramentas de IA e verificação de resultados.
