# Trilha — segurança de aplicações Python

## Pré-requisitos

Python, HTTP, banco SQL, arquivos, ambientes, testes, Git e fundamentos de sistema operacional.

## Ordem

1. Validação e encoding de saída.
2. SQL injection e parametrização.
3. Gestão de segredos, hash de senha e variáveis de ambiente.
4. Autenticação x autorização.
5. Dependências, logs e tratamento seguro de erros.
6. Revisão de código e modelagem de ameaça básica.

## Projetos

- revisar API fictícia com falhas;
- criar checklist de segurança;
- adicionar validação e testes a CRUD;
- configurar app local sem segredos no repositório.

Estude apenas em sistemas próprios/autorizados e siga escopo de testes. O objetivo desta trilha é construir e revisar defensivamente.
