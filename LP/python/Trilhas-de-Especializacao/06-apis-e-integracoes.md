# Trilha — Python para APIs e integrações

## Pré-requisitos

HTTP, JSON, erros, ambientes virtuais, segurança básica, testes e logs.

## Ordem

1. Consumir uma API documentada.
2. Timeout, retry consciente e rate limit.
3. Validar payload e versionar contrato.
4. Criar API pequena.
5. Autenticação/autorização.
6. Integração com banco e monitoramento.

## Projetos

- cliente de API com cache opcional;
- sincronizador de dados em ambiente de teste;
- API de tarefas;
- integração de dois serviços fictícios com fila/retry.
