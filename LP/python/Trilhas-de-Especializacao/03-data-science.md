# Trilha — Python para dados

## Pré-requisitos

Python básico sólido, coleções, funções, arquivos CSV/JSON, estatística básica, SQL, ambientes e visualização de dados responsável.

## Ordem

1. Limpeza/validação com biblioteca padrão.
2. SQL e modelagem.
3. Ferramenta tabular como pandas após entender tabelas.
4. Visualização e comunicação de resultado.
5. Pipeline reproduzível, testes de dados e documentação.
6. Performance/memória para conjuntos maiores.

## Projetos

- análise de vendas fictícias;
- relatório de qualidade de dados;
- dashboard ou notebook reproduzível;
- pipeline de importação CSV com validação.

Dados pessoais e dados de produção exigem controle de acesso, anonimização quando apropriado e cuidado com logs.
