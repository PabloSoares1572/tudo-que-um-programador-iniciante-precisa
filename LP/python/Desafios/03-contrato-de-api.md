# Desafio — desenhar contrato de API de tarefas

## Objetivo

Projete uma API para criar, listar, concluir e arquivar tarefas.

## Entregáveis

- lista de endpoints e métodos HTTP;
- payload de entrada e resposta;
- status codes de sucesso e erro;
- regras de autenticação/autorização;
- validação de título, status e identificador;
- plano de paginação/filtro;
- exemplos de erros sem vazar dados internos.

## Nível 2

Implemente uma versão local com FastAPI e armazenamento em memória. Escreva testes para 201, 404, 422/validação e acesso não autorizado.

## Nível 3

Use banco, migrações, configuração por ambiente, logs estruturados e documentação. Não implemente autenticação copiando código de internet sem entender hash, segredo, expiração e autorização.
