# Desafios de projeto e raciocínio

Desafios têm menos roteiro que exercícios. Não existe uma única solução correta; você será avaliado pela clareza de requisitos, tratamento de bordas, testes, documentação e decisões justificadas.

## Desafios

1. [Biblioteca CLI](./01-biblioteca-cli.md)
2. [Refatorar sem quebrar](./02-refatoracao.md)
3. [Contrato de API](./03-contrato-de-api.md)
4. [Dados, performance e segurança](./04-dados-performance-seguranca.md)

## Modo desafio

Para cada desafio importante:

- **Nível 1 — Base:** implemente o comportamento principal.
- **Nível 2 — Melhorias:** trate bordas, adicione filtros, persistência ou UX.
- **Nível 3 — Profissional:** testes, type hints, logging, documentação, segurança e configuração.
