# Projeto 10 — API REST de tarefas

> ⚫ **Profissional**

## Objetivo

Criar API com tarefas, usuários fictícios e persistência.

## Milestones

1. defina contrato e status codes;
2. implemente rotas e validação;
3. adicione serviço com regras;
4. conecte banco e migrações;
5. escreva testes unitários e de rota;
6. configure ambiente, logs e documentação;
7. revise autenticação/autorização e segurança.

## Definição de pronto

- documentação de endpoints;
- testes de erro e permissão;
- config sem segredo hardcoded;
- validação de entrada;
- erros públicos seguros;
- comando de execução local e de testes.
