# Projeto 1 — Calculadora

> 🟢 **Iniciante**

## Objetivo

Criar calculadora de terminal para soma, subtração, multiplicação e divisão.

## Requisitos base

- receber dois números;
- receber operação;
- mostrar resultado;
- impedir divisão por zero;
- informar operação inválida.

## Melhorias

- repetir até usuário escolher sair;
- guardar histórico em memória;
- formatar números;
- criar funções separadas por operação.

## Profissional

- testes para cada operação e erro;
- type hints;
- README curto;
- interface de terminal separada da lógica.

## Dica

Uma função \`calcular(a, b, operacao)\` é mais fácil de testar do que uma função que chama \`input()\`.
