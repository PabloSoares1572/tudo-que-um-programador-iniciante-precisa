# Projeto 3 — Jogo de adivinhação

> 🟢 **Iniciante**

## Objetivo

O computador escolhe número dentro de intervalo e o jogador tenta acertar.

## Requisitos base

- gerar número com \`random\`;
- receber palpite inteiro;
- informar maior/menor;
- contar tentativas;
- encerrar no acerto.

## Melhorias

- escolher dificuldade;
- limitar tentativas;
- ranking local em arquivo de teste;
- testes para função que compara palpite e alvo.

## Cuidado

\`random\` é suficiente para jogo/estudo, não para senha ou token.
