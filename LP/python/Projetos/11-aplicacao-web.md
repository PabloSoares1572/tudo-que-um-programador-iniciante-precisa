# Projeto 11 — Aplicação web

> ⚫ **Profissional**

## Objetivo

Construir aplicação web pequena, como agenda ou controle de hábitos, usando um framework escolhido conscientemente.

## Requisitos

- autenticação somente se você estudar implementação segura;
- criação/listagem/edição de dados;
- banco e migrações;
- validação de formulário/API;
- tratamento de erros;
- testes;
- configuração por ambiente;
- README e deploy de demonstração sem dados reais.

## Escolha de framework

Django ajuda quando você quer convenções, ORM e área administrativa; FastAPI atende bem APIs; Flask é flexível. Escolha um, leia documentação oficial e não faça curso superficial dos três em paralelo.
