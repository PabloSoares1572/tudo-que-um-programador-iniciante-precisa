# Projeto 4 — Pedra, papel e tesoura

> 🟢 **Iniciante**

## Objetivo

Praticar condicionais, dicionários, loops e funções em um jogo conhecido.

## Requisitos

- validar escolha do jogador;
- gerar escolha do computador;
- determinar empate/vitória/derrota;
- repetir partidas;
- mostrar placar.

## Desenho sugerido

Use uma função para validar escolha, outra para decidir vencedor e outra para a interface. Evite uma cascata enorme de condições repetidas; um dicionário de relações pode deixar a regra mais clara depois de a versão simples funcionar.
