# Projeto 2 — Conversor de unidades

> 🟢 **Iniciante**

## Objetivo

Converter temperatura, distância ou peso a partir de menu simples.

## Requisitos base

- escolha de categoria;
- valor numérico;
- conversão correta;
- saída com unidade e arredondamento.

## Melhorias

- validar opções;
- permitir várias conversões na mesma execução;
- separar fórmulas em funções;
- criar testes para valores conhecidos.

## Casos de teste

- 0 °C = 32 °F;
- 1000 m = 1 km;
- entrada não numérica deve mostrar mensagem sem encerrar de forma confusa.
