# Projeto 8 — CRUD com SQLite

> 🟡 **Intermediário → ⚫ Profissional**

## Objetivo

Criar sistema simples de estoque ou finanças com SQLite.

## Requisitos

- schema versionado/documentado;
- criação de tabela;
- inserir, listar, atualizar e remover;
- queries parametrizadas;
- transações para operações relacionadas;
- validação de dados;
- tratamento de erro de banco.

## Nível profissional

- separar repositório da regra de negócio;
- testes em banco temporário;
- índices justificados por consulta real;
- migrações quando o schema evoluir;
- README com como reiniciar dados de desenvolvimento.

Não use banco de produção/contas reais para exercício.
