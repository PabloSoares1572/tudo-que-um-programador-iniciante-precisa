# Projeto 7 — Organizador de arquivos seguro

> 🟡 **Intermediário**

## Objetivo

Organizar arquivos de uma **pasta de teste** por extensão ou data.

## Regras de segurança obrigatórias

- receber diretório explicitamente;
- nunca apontar padrão para pasta pessoal;
- listar ações antes de executar;
- implementar modo simulação;
- não sobrescrever arquivo destino sem política clara;
- registrar resultado;
- testar com cópias descartáveis.

## Milestones

1. listar arquivos;
2. calcular destino sem mover;
3. imprimir plano;
4. executar apenas com confirmação;
5. testes para colisão, extensão ausente e subdiretório.

Este projeto ensina automação responsável, não exclusão/movimentação em massa.
