# Projeto 9 — Consumidor de API

> 🟡 **Intermediário**

## Objetivo

Consumir API pública/autorizada e mostrar dados úteis em terminal.

## Requisitos

- fonte com documentação e termos claros;
- URL configurável;
- timeout;
- verificação de status;
- validação do JSON;
- mensagens para falha de rede;
- cache simples apenas se necessário.

## Testes

Não dependa da API real para todos os testes. Isole uma função que interpreta payload e use respostas simuladas. Nunca inclua token real em repositório.
