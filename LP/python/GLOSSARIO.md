# Glossário de Python e programação

| Termo | Significado prático |
| --- | --- |
| Algoritmo | Sequência finita de passos para resolver um problema |
| Variável | Nome que referencia um valor durante a execução |
| Tipo | Categoria do valor, como `int`, `str` ou `list` |
| Função | Bloco reutilizável que recebe dados e pode devolver um resultado |
| Parâmetro | Nome declarado pela função para receber um valor |
| Argumento | Valor enviado na chamada de uma função |
| Retorno | Valor devolvido por `return` |
| Módulo | Arquivo Python que pode ser importado |
| Pacote | Organização de módulos em diretórios importáveis |
| Biblioteca | Conjunto reutilizável de módulos e recursos |
| Framework | Ferramenta que define uma estrutura e chama partes do seu código |
| Classe | Modelo para criar objetos com estado e comportamento |
| Instância | Objeto criado a partir de uma classe |
| Atributo | Dado associado a um objeto ou classe |
| Método | Função definida dentro de uma classe |
| API | Interface pela qual programas trocam dados/ações |
| Endpoint | Endereço/rota específica de uma API |
| HTTP | Protocolo comum de comunicação na web |
| JSON | Formato textual muito usado para troca de dados |
| Exception | Evento de erro que pode ser tratado pelo programa |
| Traceback | Caminho mostrado pelo Python até o ponto do erro |
| Debugger | Ferramenta para pausar e inspecionar a execução |
| Processo | Programa em execução com recursos próprios |
| Thread | Linha de execução dentro de um processo |
| Async | Modelo cooperativo para esperar operações sem bloquear outras tarefas compatíveis |
| Banco de dados | Sistema organizado para armazenar e consultar dados |
| Query | Comando/consulta enviado ao banco de dados |
| ORM | Camada que mapeia objetos para dados de banco; não substitui aprender SQL |
| Ambiente virtual | Instalação isolada de pacotes para um projeto |
| Dependência | Pacote externo de que o projeto precisa |

Termos novos devem ser entendidos no módulo em que aparecem; este glossário é uma referência rápida, não um substituto da aula.
