# Python — do zero ao avançado

> Uma formação prática para quem pode começar pensando: **“eu nunca programei”**.

Python é uma linguagem de programação de propósito geral. Sua sintaxe legível e sua ampla biblioteca padrão ajudam em automação, backend, dados, testes, scripts, ferramentas de linha de comando, ciência de dados e muito mais.

## Para que Python serve?

- automatizar tarefas repetitivas;
- criar programas de terminal, APIs e backends web;
- trabalhar com arquivos, planilhas, dados e bancos de dados;
- escrever testes, ferramentas internas e scripts DevOps;
- estudar dados, IA e machine learning depois de dominar a base.

## Vantagens e limites

| Vantagens | Limites e cuidados |
| --- | --- |
| Sintaxe clara e ecossistema grande | Não é a melhor escolha para tudo; jogos 3D e partes extremamente críticas de desempenho podem exigir outra tecnologia |
| Funciona em Windows, Linux e macOS | Dependências e versões precisam ser isoladas por projeto |
| Bom para aprender lógica e construir projetos rápido | Código “curto” não é automaticamente código correto, seguro ou fácil de manter |
| Biblioteca padrão muito útil | Projetos profissionais exigem testes, revisão, documentação e versionamento |

## Como seguir esta formação

1. Leia [Introdução](./00-Introducao/README.md) e prepare o ambiente.
2. Avance do módulo 02 ao 12 sem pular fundamentos.
3. Faça as revisões e os exercícios; tente antes de ver qualquer solução.
4. A partir do intermediário, crie projetos em Git e use ambiente virtual.
5. Escolha uma [trilha de especialização](./Trilhas-de-Especializacao/README.md) somente após consolidar o núcleo.

> 🟢 **Regra de ouro:** digite os exemplos, altere valores, provoque erros seguros e descubra o que muda. Ler programação sem executar é como ler sobre direção sem sentar no carro.

## Executando exemplos e projetos

Em uma pasta de projeto, crie um arquivo como `main.py` e execute com o interpretador Python:

```text
Windows: py main.py
Linux/macOS: python3 main.py
```

Quando o projeto usar bibliotecas externas, siga primeiro o módulo de [ambientes e dependências](./18-Ambientes-e-Dependencias/README.md). Não instale pacotes aleatórios globalmente “até funcionar”.
