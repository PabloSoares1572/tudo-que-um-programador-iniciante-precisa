# Terminal e shell

Terminal é a interface onde você digita comandos; shell é o programa que interpreta esses comandos. PowerShell, bash e zsh têm sintaxes diferentes.

Python também pode ser iniciado no terminal:

\`\`\`text
python3
>>> 2 + 2
4
\`\`\`

O prompt interativo é ótimo para experimentar expressões pequenas. Para programa reutilizável, salve em arquivo \`.py\`.

Antes de executar comandos de arquivo, confirme diretório atual. Um comando correto no diretório errado pode afetar o alvo errado.
