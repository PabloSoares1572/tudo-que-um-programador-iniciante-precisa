# SQL e bancos relacionais

SQL é linguagem para consultar e modificar dados relacionais. Uma tabela tem colunas e linhas; chave primária identifica; chave estrangeira relaciona.

Operações comuns: \`SELECT\`, \`INSERT\`, \`UPDATE\`, \`DELETE\`. Em Python, use parâmetros do driver para valores externos. String concatenada para formar query permite SQL injection.

ORM ajuda em produtividade, mas não apaga conceitos: índices, transações, consistência e query lenta continuam existindo. Aprenda SQL básico antes de delegar tudo a um ORM.
