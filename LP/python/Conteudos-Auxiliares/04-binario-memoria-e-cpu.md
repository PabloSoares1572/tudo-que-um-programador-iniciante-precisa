# Binário, hexadecimal, memória e CPU

- **bit:** 0 ou 1;
- **byte:** normalmente 8 bits;
- **binário:** base 2;
- **hexadecimal:** base 16, útil para representar bytes de forma compacta;
- **RAM:** memória temporária usada durante execução;
- **CPU:** executa instruções;
- **SSD/HDD:** armazenamento persistente.

Python esconde muitos detalhes, mas eles ajudam a entender por que arquivo grande usa memória, por que I/O espera disco/rede e por que algoritmo O(n²) pode crescer rápido.

Não confunda memória RAM com armazenamento em disco; um generator pode reduzir RAM, mas não torna disco ou rede instantâneos.
