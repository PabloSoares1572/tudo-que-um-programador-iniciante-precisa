# Git e histórico

Git registra versões do projeto. Um commit é uma fotografia com mensagem; branch isola linha de trabalho; merge junta mudanças compatíveis; repositório remoto permite colaboração/backup.

Git não é backup mágico de segredo: se token foi commitado, pode continuar no histórico. Revogue o segredo e siga processo de limpeza apropriado.

Use histórico para responder: o que mudou, por que mudou, qual teste acompanha a mudança e como reverter com segurança.
