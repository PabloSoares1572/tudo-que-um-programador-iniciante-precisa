# Aprender biblioteca nova

1. Confirme o nome e a documentação oficial.
2. Leia a instalação e a versão suportada.
3. Crie ambiente virtual.
4. Faça exemplo mínimo isolado.
5. Leia API da função que pretende usar.
6. Teste erro, timeout e dados inválidos.
7. Integre em pequena parte do projeto.
8. Registre dependência e motivo no README/configuração.

Evite instalar três bibliotecas que fazem a mesma coisa antes de entender o problema. Uma ferramenta bem compreendida vale mais que uma lista enorme no \`requirements.txt\`.
