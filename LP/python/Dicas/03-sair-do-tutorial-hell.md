# Como sair do tutorial hell

Tutorial hell acontece quando você acompanha muitos vídeos, mas trava sem roteiro. A saída é reduzir a ajuda aos poucos.

1. Refaça exemplo sem olhar.
2. Mude requisito: adicione validação, arquivo ou filtro.
3. Faça exercício parecido do zero.
4. Comece projeto pequeno e divida em tarefas.
5. Use IA/documentação como pista, não como gerador de projeto inteiro.
6. Publique README e peça revisão objetiva.

Não espere “estar pronto” para projeto; use projeto pequeno para descobrir o que falta estudar.
