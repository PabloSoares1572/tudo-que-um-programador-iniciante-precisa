# Exercícios progressivos

Os exercícios são parte do curso, não um extra. Tente primeiro sem ver solução. Se travar, releia o módulo, escreva exemplos menores e use a dica; só então compare com a referência.

## Como praticar

1. Crie uma pasta por exercício.
2. Escreva casos de teste antes de programar.
3. Teste entrada normal, limite e inválida.
4. Dê nomes claros.
5. Compare solução por comportamento, não por quantidade de linhas.
