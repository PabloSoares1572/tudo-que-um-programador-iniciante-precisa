## Como avaliar uma resposta técnica

1. Prefira documentação do projeto/ferramenta.
2. Confira a versão citada e a data de publicação.
3. Não copie comandos que pedem permissões elevadas sem entender o efeito.
4. Teste em projeto de exemplo, com ambiente virtual e dados descartáveis.
