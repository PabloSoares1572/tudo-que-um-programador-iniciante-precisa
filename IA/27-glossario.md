# 27 — Glossário de IA

| Termo | Significado simples |
| --- | --- |
| AI / IA | Inteligência Artificial: sistemas que executam tarefas associadas a percepção, linguagem ou decisão |
| AGI | Ideia de uma IA geral com capacidades amplas; não é sinônimo de assistente atual |
| LLM | Large Language Model: modelo de linguagem grande |
| GPT | Sigla usada em uma família de modelos generativos pré-treinados; o nome não garante recurso ou versão |
| Transformer | Arquitetura que relaciona partes de uma sequência, muito usada em modelos de linguagem |
| Token | Unidade de texto processada pelo modelo |
| Prompt | Instrução e contexto enviados ao modelo |
| System prompt | Instruções de mais alto nível definidas por uma plataforma ou aplicação |
| Contexto | Informações fornecidas para orientar a resposta |
| Context window | Limite de informação que o modelo considera de uma vez |
| Alucinação | Saída plausível, mas incorreta ou sem base suficiente |
| Temperature | Configuração que pode afetar variedade das respostas em algumas APIs/modelos |
| Embedding | Representação numérica de significado |
| Banco vetorial | Sistema otimizado para armazenar e buscar vetores/embeddings |
| RAG | Geração aumentada por recuperação de documentos relevantes |
| Fine-tuning | Ajuste adicional de um modelo com dados especializados |
| Agente | Sistema que combina modelo, instruções e ferramentas para executar etapas |
| Tool calling | Uso de uma ferramenta externa por meio de parâmetros estruturados |
| Multimodal | Capaz de trabalhar com texto, imagem, áudio ou vídeo |
| API | Interface para sistemas trocarem dados programaticamente |
| MCP | Protocolo para conectar modelos a ferramentas e fontes de contexto; recursos variam por implementação |
| Inferência | Momento em que o modelo gera resposta a partir de uma entrada |
| Treinamento | Processo de ajustar o modelo com dados e objetivos |
| Guardrail | Regra ou controle para reduzir comportamentos indesejados |
| Prompt injection | Tentativa de fazer um sistema seguir instruções maliciosas presentes em conteúdo externo |
| Grounding | Ancorar resposta em fonte, dado ou contexto específico |
| Chunk | Trecho de documento usado em busca/RAG |
| Reranking | Reordenar resultados recuperados por relevância |
| Avaliação (eval) | Conjunto de testes para medir qualidade de um fluxo de IA |
| Human-in-the-loop | Pessoa revisa ou aprova parte crítica do processo |
| Latência | Tempo até a resposta chegar |
| Rate limit | Limite de chamadas permitido em determinado período |

Se encontrar um termo novo, procure primeiro a definição na documentação ou artigo técnico da ferramenta usada e registre o contexto em que ele aparece.
