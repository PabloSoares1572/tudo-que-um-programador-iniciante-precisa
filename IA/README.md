# Guia prático de Inteligência Artificial

Este material é um curso gratuito, em português brasileiro, para aprender a **entender, usar e avaliar Inteligência Artificial** — desde a primeira conversa com um assistente até automações, APIs, RAG e agentes.

> **Objetivo:** transformar IA em uma ferramenta de apoio ao raciocínio, estudo e trabalho. Ela não substitui verificação, responsabilidade ou conhecimento de base.

## Para quem é

- Pessoas começando do zero.
- Estudantes que querem aprender com mais método.
- Profissionais que querem escrever, pesquisar, organizar e automatizar melhor.
- Programadores que desejam usar IA com segurança em projetos reais.

## Pré-requisitos

Não é preciso saber programar para começar. Para os capítulos de APIs, RAG e automação, ajuda já conhecer lógica, HTTP, JSON e Git, mas cada conceito é introduzido no caminho.

## Como estudar este guia

1. Leia um capítulo curto.
2. Copie um exemplo e adapte ao seu caso real.
3. Compare a primeira resposta com uma versão melhorada do prompt.
4. Registre o que funcionou em uma biblioteca pessoal de prompts.
5. Verifique informações importantes em fontes confiáveis.

## Regra de ouro

Quanto maior o impacto de uma resposta, maior deve ser sua verificação. Use IA para acelerar o trabalho; use fontes, testes e pensamento crítico para decidir.
