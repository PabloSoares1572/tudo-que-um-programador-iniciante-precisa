# 17 — Limitações e alucinações

## O que é uma alucinação?

É uma informação produzida com aparência de plausibilidade, mas que não é sustentada pelos fatos ou pelo contexto fornecido. Pode ser uma data, uma citação, um recurso de produto, uma linha de código, um cálculo ou uma interpretação.

## Por que acontece?

O modelo foi criado para gerar continuidades úteis, não para provar automaticamente cada frase. Ambiguidade, lacunas de contexto, dados antigos e pedidos para “não admitir erro” aumentam o risco.

## Formas comuns

| Tipo | Exemplo | Defesa |
| --- | --- | --- |
| Fato inventado | Estatística sem fonte | Exigir fonte verificável |
| Referência falsa | Artigo ou link que não existe | Abrir e conferir a fonte |
| Código plausível | Método inexistente na biblioteca | Rodar testes e consultar documentação |
| Cálculo errado | Percentual aplicado sobre base errada | Reproduzir em planilha/calculadora |
| Excesso de certeza | Resposta sem ressalva sobre tema incerto | Pedir suposições e limites |
| Contexto perdido | Regra anterior ignorada | Reenviar requisitos críticos |

## Protocolo de verificação

1. Marque afirmações importantes.
2. Classifique: fato, inferência ou sugestão.
3. Encontre fonte primária/atual para fatos.
4. Reproduza cálculos e testes.
5. Peça contraexemplos e condições de falha.
6. Só então use o resultado para decidir ou publicar.

## Prompt para honestidade útil

> Responda usando apenas o contexto fornecido. Separe: (a) fatos explícitos, (b) inferências razoáveis e (c) pontos sem evidência. Para cada item de (c), diga qual dado ou fonte seria necessário. Não preencha lacunas com suposições apresentadas como fato.

## Informação desatualizada

Produtos, preços, leis, políticas e bibliotecas mudam. Uma resposta treinada em dados históricos pode não refletir a versão atual. Quando a atualidade importa, pesquise fontes oficiais e registre a data de consulta.

## Não use IA como única base em

- diagnóstico médico, tratamento ou emergência;
- aconselhamento jurídico específico;
- decisão financeira relevante;
- segurança física ou operacional;
- publicação de fatos sem fonte;
- mudanças de produção sem teste e revisão.

IA continua sendo valiosa nesses cenários para preparar perguntas, resumir materiais fornecidos e organizar opções — com revisão qualificada.
