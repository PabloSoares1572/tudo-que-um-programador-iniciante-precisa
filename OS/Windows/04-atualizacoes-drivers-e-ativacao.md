# Atualizações, drivers e ativação legítima

## Ordem recomendada após instalar

1. Conecte à rede segura.
2. Rode Windows Update e reinicie quando solicitado.
3. Instale drivers do fabricante do notebook/placa-mãe quando necessário.
4. Atualize driver de GPU diretamente de AMD, Intel ou NVIDIA quando esse for o caminho recomendado para sua GPU.
5. Verifique Gerenciador de Dispositivos e funções reais: Wi‑Fi, áudio, USB, Bluetooth, monitor e energia.
6. Instale programas de fontes oficiais.

## Onde buscar drivers

| Situação | Fonte preferida |
| --- | --- |
| Notebook | Página de suporte do fabricante para o modelo exato |
| Placa-mãe/chipset | Fabricante da placa-mãe ou OEM do PC |
| GPU | AMD, Intel ou NVIDIA, conforme fabricante da GPU |
| Windows Update | Atualizações normais e muitos drivers compatíveis |
| Site de “driver updater” aleatório | Evite; pode instalar pacote errado, anúncios ou malware |

## Atualizações não são inimigas

Atualizações trazem correções de segurança, compatibilidade e drivers. O procedimento correto não é “desativar tudo”: é atualizar com energia estável, espaço disponível e backup antes de grandes mudanças. Se uma atualização falhar, anote código/horário e use [troubleshooting](./07-troubleshooting.md).

## Drivers: não atualize por esporte

Atualize para resolver problema, corrigir vulnerabilidade, ganhar compatibilidade ou seguir recomendação do fabricante. Se está tudo estável, criar ponto de restauração e anotar versão atual antes de uma troca grande é prudente.

## Ativação

A ativação valida licença, não “otimiza” o PC. Use apenas:

- chave adquirida por canal legítimo;
- licença digital do dispositivo/conta, quando aplicável;
- licença fornecida por empresa/escola conforme política;
- suporte oficial para problema de ativação.

Não compartilhe chaves em prints, repositórios, chats ou arquivos públicos.
