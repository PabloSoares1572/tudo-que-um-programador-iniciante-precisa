# Windows — versões e edições

## Versão não é edição

- **Versão:** geração e atualização do Windows, como Windows 10 ou Windows 11.
- **Edição:** conjunto de recursos/licenciamento dentro da versão, como Home, Pro ou Enterprise.
- **Canal/ciclo de vida:** regras de suporte e atualizações que podem variar por edição e versão.

## Estado de suporte: como interpretar

> ⚠️ O estado de suporte muda. Consulte sempre a [página oficial de ciclo de vida](https://learn.microsoft.com/lifecycle/) antes de decidir.

| Categoria | Uso recomendado |
| --- | --- |
| Atualmente suportada | Melhor opção para PC conectado à internet, se o hardware e a licença forem compatíveis |
| Sem suporte geral | Somente legado, laboratório isolado ou migração planejada; não recomendada para uso cotidiano conectado |
| Histórica | Útil para estudo de compatibilidade, não para segurança cotidiana |
| LTSC/IoT/empresa | Tem ciclo próprio e uso/licenciamento específico; não é atalho genérico para “ter Windows leve” |

Na data desta documentação, a Microsoft informa que o suporte geral do Windows 10 terminou em 14/10/2025. O sistema pode continuar funcionando, mas não recebe o mesmo fluxo de correções gerais de segurança e suporte. Não instale uma versão antiga só porque parece familiar.

## Edições principais

| Edição | Perfil típico | Diferenças práticas |
| --- | --- | --- |
| Home | Uso doméstico | Recursos básicos para usuário comum; algumas funções profissionais podem faltar |
| Pro | Usuário avançado, pequeno negócio, desenvolvimento | Inclui recursos de administração/criptografia/virtualização conforme versão e hardware |
| Enterprise | Organizações | Gestão, segurança e licenciamento corporativos; normalmente entregue por empresa |
| Education | Instituições de ensino | Recursos voltados ao ambiente educacional e licenciamento institucional |
| Pro for Workstations | Workstations específicas | Recursos voltados a cenários de hardware/armazenamento profissionais, quando aplicável |
| Windows Server | Servidores | Produto diferente para infraestrutura; não é “Windows comum mais completo” |

## O que realmente diferencia edições

Não escolha por marketing. Verifique se você precisa de recurso concreto:

- BitLocker completo/gerenciamento de criptografia;
- acesso a domínio ou políticas corporativas;
- Área de Trabalho Remota como host;
- Hyper-V e virtualização;
- gestão empresarial, identidade e compliance;
- recursos de workstation/servidor.

Disponibilidade pode depender de versão, hardware, região e política corporativa. A [documentação da Microsoft](https://learn.microsoft.com/windows/) deve ser a fonte final.

## Perguntas antes de escolher

1. Meu PC atende aos requisitos oficiais da versão atual?
2. Preciso de recursos Pro/Enterprise por um motivo real?
3. Tenho licença legítima para a edição escolhida?
4. Algum programa, periférico ou jogo exige Windows específico?
5. Estou tentando resolver lentidão com edição errada em vez de diagnóstico de hardware/software?
