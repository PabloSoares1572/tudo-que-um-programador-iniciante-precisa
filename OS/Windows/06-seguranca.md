# Segurança no Windows

## Base de segurança

1. Atualizações automáticas e reinicializações planejadas.
2. Conta de usuário normal para uso diário; administração somente quando necessário.
3. Microsoft Defender e firewall ativos, salvo política corporativa documentada.
4. Senhas únicas em gerenciador de senhas e MFA para contas importantes.
5. Backup testado e chave de recuperação de criptografia guardada.
6. Downloads somente de fontes oficiais/confiáveis.

## Recursos importantes

| Recurso | Para que serve | Cuidado |
| --- | --- | --- |
| Microsoft Defender | Proteção antimalware integrada | Mantenha atualizado; não ignore alertas sem investigar |
| Firewall | Controla conexões de rede | Não desative só para “fazer funcionar”; crie regra específica se necessário |
| UAC | Pede confirmação para ações administrativas | Não deixe desativado por conveniência |
| BitLocker | Criptografa unidade conforme edição/configuração | Guarde chave de recuperação antes de mexer em boot/firmware |
| Windows Update | Corrige falhas e compatibilidade | Não bloqueie indefinidamente |

## Phishing e downloads

Desconfie de urgência, links encurtados, arquivos inesperados, instaladores “premium grátis” e pedidos de código MFA. O endereço, a origem e a assinatura do arquivo importam mais que o ícone bonito.

## Em empresa ou escola

Respeite políticas de TI. Não instale ferramentas de acesso remoto, VPN, antivírus ou scripts sem autorização. Dados de trabalho não devem ir para pendrive ou nuvem pessoal sem permissão.

## Recuperação é segurança

Faça backup de arquivos, teste restauração, crie mídia de recuperação quando apropriado e mantenha acesso à conta Microsoft/conta local e chaves de recuperação. Segurança sem recuperação pode deixar você sem os próprios dados.
