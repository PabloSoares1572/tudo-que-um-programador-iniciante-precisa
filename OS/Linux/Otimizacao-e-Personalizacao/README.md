# Otimização e personalização Linux

Esta área separa dois objetivos diferentes:

- **Otimização:** medir e melhorar comportamento de desempenho, energia, armazenamento ou estabilidade.
- **Personalização:** mudar aparência, atalhos, fluxo de trabalho e ambiente gráfico.

Misturar os dois leva a “tweaks” que quebram o sistema sem melhorar performance.
