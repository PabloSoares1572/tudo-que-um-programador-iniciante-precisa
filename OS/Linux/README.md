## Como praticar sem risco

1. Use máquina virtual para comandos de administração, scripts e partições.
2. Crie usuário/pasta de teste em vez de operar na sua pasta principal.
3. Leia `man comando` ou `comando --help` antes de adicionar opções.
4. Use `ls`, `pwd`, `lsblk -f`, `findmnt` ou saída de diagnóstico antes de comandos que modificam estado.
5. Mantenha backup e snapshots quando houver dados importantes.

> ⚠️ O Linux dá muito controle. Isso é ótimo quando você entende a ação — e perigoso quando executa algo vindo de fórum, vídeo ou IA sem verificar.
