# Parrot OS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Debian |
| Filosofia | Segurança, privacidade e desenvolvimento, com edições diferentes conforme o projeto |
| Dificuldade | 🟡/🔴 |
| Pacotes | APT/`.deb` |

## Para que serve

Parrot OS pode atender a laboratório de segurança, privacidade e desenvolvimento, dependendo da edição. Não confunda uma edição com ferramentas de segurança com sistema automaticamente protegido contra qualquer ameaça.

## Pontos positivos

- foco declarado em segurança/privacidade;
- opções de edição/ambiente conforme o projeto;
- base Debian familiar para quem já conhece APT.

## Pontos de atenção

- ferramentas de pentest exigem autorização;
- não é necessário para aprender Linux básico;
- compare edição, suporte e documentação atuais antes de instalar.

## Para quem recomendo / não recomendo

**Recomendo** para laboratório autorizado e usuário que sabe por que escolhe a distribuição.  
**Não recomendo** como atalho para “ficar anônimo”, para primeiro Linux sem estudo ou para testar segurança de terceiros.

## Requisitos, desktop e pacotes

Use [Parrot OS oficial](https://parrotsec.org/download/). Veja na página atual qual imagem se aplica ao seu objetivo e siga instruções de verificação/publicação do projeto.

## Instalação específica

1. Primeiro prefira VM, especialmente para ferramentas de segurança.
2. Baixe ISO oficial e verifique integridade conforme instrução atual.
3. Teste hardware em live USB antes de instalar no disco.
4. Para dual boot, preserve Windows/EFI e use espaço não alocado.
5. Atualize somente pelos repositórios oficiais do Parrot e mantenha prática dentro de autorização.
