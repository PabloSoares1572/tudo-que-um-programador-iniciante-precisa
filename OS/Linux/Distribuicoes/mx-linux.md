# MX Linux

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Debian |
| Filosofia | Desktop estável, ferramentas próprias e opções para hardware modesto |
| Dificuldade | 🟢/🟡 |
| Pacotes | APT/`.deb` |

## Para que serve

MX Linux é uma opção de desktop para quem valoriza base Debian, ferramentas gráficas e uso em PCs mais modestos, dependendo da edição/desktop escolhidos.

## Pontos positivos

- foco em desktop prático e estável;
- ferramentas próprias e comunidade;
- pode ser opção interessante para hardware menos recente.

## Pontos de atenção

- não escolha apenas por fama de “leve”: teste no seu hardware;
- versões de software seguem a base/ciclo;
- para servidor corporativo, Debian/RHEL/Ubuntu Server podem ser caminhos mais diretos.

## Para quem recomendo / não recomendo

**Recomendo** para desktop estável, PC modesto e usuário que aceita aprender APT.  
**Não recomendo** se você quer versões mais novas de tudo, desktop corporativo específico ou primeira experiência sem testar interface.

## Requisitos, desktop e pacotes

Consulte [MX Linux](https://mxlinux.org/) e documentação atual para ISO, ambientes e requisitos. Use APT para manutenção de pacotes.

## Instalação específica

1. Baixe somente no site oficial/mirrors indicados.
2. Verifique imagem quando o projeto disponibilizar instruções.
3. Teste live USB; escolha edição/desktop pelo desempenho real.
4. Em dual boot, siga [Instalação geral](./INSTALACAO-GERAL.md) e não altere partições Windows fora do espaço planejado.
5. Atualize após primeiro boot e teste rede/GPU.
