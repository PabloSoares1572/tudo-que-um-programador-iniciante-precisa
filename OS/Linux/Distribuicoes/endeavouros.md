# EndeavourOS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Arch Linux |
| Filosofia | Instalação guiada com sistema próximo do Arch e comunidade/documentação próprias |
| Lançamento | Rolling release |
| Dificuldade | 🟡/🔴 |
| Pacotes | Pacman e repositórios do projeto/Arch conforme configuração |

## Para que serve

EndeavourOS é para quem quer entrar no ecossistema Arch com instalador, mas ainda deseja aprender manutenção e usar documentação. É menos “abstraído” do que algumas derivadas e não torna Arch adequado a qualquer pessoa automaticamente.

## Pontos positivos

- instalador e opções de ambiente;
- proximidade com ecossistema Arch;
- comunidade para transição ao modelo rolling.

## Pontos de atenção

- updates rolling exigem rotina e leitura;
- AUR/pacotes comunitários não são instalação sem risco;
- guias devem ser compatíveis com EndeavourOS/Arch e a versão atual.

## Para quem recomendo / não recomendo

**Recomendo** para quem já aprendeu terminal básico e quer conhecer Arch.  
**Não recomendo** como PC de produção sem backup/tempo de manutenção ou primeiro Linux de pessoa que só quer interface simples.

## Requisitos, desktop e pacotes

Veja [EndeavourOS](https://endeavouros.com/) para imagens, instalações e notas atuais. Use Pacman e atualize sistema completo conforme orientação do projeto.

## Instalação específica

1. Use ISO oficial e escolha desktop/instalação online/offline somente entendendo diferenças.
2. Teste hardware em live USB.
3. Particione somente espaço planejado e preserve partições existentes no dual boot.
4. Após instalação, configure espelhos/rede conforme documentação oficial e atualize de forma completa.
5. Antes de usar pacote comunitário, leia PKGBUILD/origem e saiba como remover/reverter.
