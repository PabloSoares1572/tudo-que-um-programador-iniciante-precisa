# Nobara

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Fedora, com decisões próprias do projeto |
| Filosofia | Desktop com foco em jogos, criação e conveniências multimídia |
| Dificuldade | 🟡 |
| Pacotes | Ecossistema RPM/DNF e configurações do projeto |

## Para que serve

Nobara mira usuário de desktop que quer reduzir etapas iniciais para jogos/multimídia. É uma distribuição comunitária com decisões específicas; trate-a como projeto próprio, não como “Fedora oficial com extras”.

## Pontos positivos

- foco em experiência de desktop/jogos;
- configurações e ferramentas que podem economizar tempo para alguns usuários;
- base familiar para quem conhece Fedora.

## Pontos de atenção

- depende de equipe/projeto diferente do Fedora;
- suporte, ritmo de atualização e compatibilidade precisam ser confirmados no projeto;
- não é ideal para produção corporativa só porque é baseada em Fedora.

## Para quem recomendo / não recomendo

**Recomendo** para PC pessoal de jogos/multimídia após testar hardware e jogos reais.  
**Não recomendo** para servidor, ambiente corporativo crítico ou iniciante que não quer acompanhar documentação de uma distro comunitária.

## Requisitos, desktop e pacotes

Consulte [Nobara Project](https://nobaraproject.org/) para ISO, requisitos, imagens e instruções atuais. Confirme driver GPU e edição para seu hardware antes de instalar.

## Instalação específica

1. Baixe somente do projeto oficial.
2. Teste live USB com seu Wi‑Fi, GPU, áudio e jogo/launcher importante quando possível.
3. Não substitua Windows em dual boot sem backup e sem confirmar que seus jogos funcionam.
4. Use espaço não alocado e leia o resumo do instalador.
5. Atualize pelo mecanismo documentado pelo Nobara, evitando misturar repositórios Fedora aleatórios.
