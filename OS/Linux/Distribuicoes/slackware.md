| Família/base | Slackware, independente |

| Dificuldade | 🔴 |

## Para que serve

Slackware é historicamente importante e pode ensinar administração mais manual. Não é distribuição orientada a conveniência de iniciante nem escolha padrão para desktop moderno sem pesquisa.

## Pontos positivos

- tradição e filosofia simples/controle explícito;
- bom para entender administração sem muitas camadas;
- histórico relevante no ecossistema Linux.

## Pontos de atenção

- menos automatismos e comunidade menor que distros populares;
- fluxo de pacotes/serviços difere de APT/DNF/Pacman;
- exige leitura de documentação e tempo de manutenção.

## Para quem recomendo / não recomendo

**Recomendo** para laboratório, história Linux e usuário experiente.  
**Não recomendo** para primeiro Linux, PC de produção sem conhecimento ou quem quer instalação/configuração altamente guiada.

## Requisitos, desktop e pacotes

Consulte [Slackware](https://www.slackware.com/) para imagem, arquitetura, release e documentação atuais.

## Instalação específica

1. Prefira VM para primeiro contato.
2. Baixe mídia e verificação somente do projeto oficial.
3. Leia documentação da versão antes de particionar/configurar boot.
4. Após instalar, entenda método de atualização e serviços do Slackware antes de adicionar software de terceiros.
