# Linux Mint

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Base Ubuntu/Debian conforme edição, com foco principal no desktop Mint |
| Filosofia | Desktop pronto para uso, familiar e com manutenção simples |
| Lançamento | Lançamentos com suporte prolongado conforme política do projeto |
| Dificuldade | 🟢 Iniciante |
| Pacotes | APT/`.deb`, com integração a outros formatos conforme configuração |

## Para que serve

Linux Mint é especialmente indicado para desktop/notebook, usuários migrando de Windows, estudos e uso doméstico. Cinnamon é sua interface mais conhecida; Xfce é opção mais leve e MATE oferece experiência tradicional.

## Pontos positivos

- interface familiar e foco em uso desktop;
- ferramentas gráficas próprias para atualização, drivers e snapshots em cenários suportados;
- boa documentação para instalação e problemas comuns;
- edições adequadas a diferentes níveis de hardware.

## Pontos de atenção

- não é a melhor escolha para quem quer aprender administração de servidor como foco principal;
- versões de pacotes seguem a base/ciclo da distribuição;
- escolher Cinnamon em PC fraco pode não ser ideal — compare Xfce/MATE.

## Para quem recomendo / não recomendo

**Recomendo** como uma das escolhas mais fáceis para primeiro Linux desktop.  
**Não recomendo** se seu objetivo central for ambiente corporativo RHEL, sistema imutável/atômico ou um laboratório Arch/Gentoo.

## Requisitos, desktop e pacotes

Confira edição e requisitos atuais no [site oficial](https://linuxmint.com/download.php). Cinnamon foca experiência completa; Xfce costuma reduzir consumo; MATE prioriza um fluxo clássico. O gerenciador base é APT.

## Instalação específica

1. Baixe ISO em [Linux Mint](https://linuxmint.com/download.php).
2. Leia a [documentação de instalação](https://linuxmint.com/documentation.php) e verifique imagem quando o projeto instruir.
3. Teste live USB e escolha a edição compatível com hardware.
4. Para dual boot, use o instalador ao lado somente após backup e espaço não alocado confirmado.
5. Após instalar, atualize pelo Update Manager e teste drivers/periféricos.
