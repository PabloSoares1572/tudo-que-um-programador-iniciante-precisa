# Tails

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Sistema especializado em privacidade/anônimo, com foco em uso amnésico via mídia USB |
| Filosofia | Reduzir rastros locais e apoiar privacidade em cenários definidos |
| Dificuldade | 🟡; exige entender modelo de ameaça |
| Pacotes | Não deve ser tratado como desktop Linux comum para instalar qualquer coisa |

## Para que serve

Tails é específico para privacidade e uso a partir de USB. Ele não torna o usuário invisível, não protege contra computador comprometido, não elimina erros de comportamento e não substitui práticas legais/seguras.

## Pontos positivos

- foco explícito em privacidade;
- guia oficial de instalação/verificação;
- desenho voltado a não deixar persistência por padrão, salvo recursos configurados.

## Pontos de atenção

- não é sistema diário para jogos/programação convencional;
- modelo de ameaça deve guiar uso; não prometa anonimato absoluto;
- não instale software ou altere persistência sem entender efeito de segurança.

## Para quem recomendo / não recomendo

**Recomendo** para quem tem necessidade legítima de privacidade e estuda documentação oficial.  
**Não recomendo** como “Linux mais seguro” para qualquer pessoa, dual boot comum ou ferramenta para atividades ilícitas.

## Requisitos, desktop e pacotes

Use [Tails oficial](https://tails.net/) e o [guia de instalação](https://tails.net/install/index.en.html). Requisitos e dispositivos suportados devem ser conferidos no dia da instalação.

## Instalação específica

1. Leia o modelo de ameaça e guia oficial antes de baixar.
2. Baixe e verifique usando somente mecanismos Tails.
3. Crie USB conforme método oficial; ele será alterado.
4. Teste em máquina que você controla e não dependa de Tails como solução mágica.
5. Proteja mídia, senhas e qualquer armazenamento persistente configurado.
