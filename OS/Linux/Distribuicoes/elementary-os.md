# elementary OS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Ecossistema Ubuntu/Debian conforme release |
| Filosofia | Desktop coeso, minimalista e orientado a design |
| Dificuldade | 🟢/🟡 |
| Pacotes | Base `.deb`/APT e loja/formato do projeto conforme release |

## Para que serve

elementary OS atende bem a quem quer desktop visualmente consistente e fluxo simples. É menos indicado para quem espera toda opção de personalização exposta ou quer uma distribuição de servidor.

## Pontos positivos

- interface e experiência de aplicativos consistentes;
- documentação de instalação clara;
- foco em desktop e privacidade/usabilidade.

## Pontos de atenção

- escolhas de design podem ser mais opinionadas;
- verifique requisitos/arquiteturas atuais antes de baixar;
- software/driver deve vir de fonte compatível com a base.

## Para quem recomendo / não recomendo

**Recomendo** para desktop, estudo e usuário que prefere experiência minimalista.  
**Não recomendo** para hardware muito limitado sem testar, servidor ou quem quer alterar profundamente todos os componentes desde o primeiro dia.

## Requisitos, desktop e pacotes

Consulte [elementary OS](https://elementary.io/) e sua [documentação de instalação](https://elementary.io/docs/installation). O ambiente do projeto é Pantheon; requisitos dependem da edição e arquitetura.

## Instalação específica

1. Baixe ISO somente em `elementary.io`.
2. A documentação oficial indica mídia USB e ferramenta de gravação; ela será apagada.
3. Faça live boot e confirme dispositivos.
4. Em dual boot, preserve espaço/partições existentes conforme [guia geral](./INSTALACAO-GERAL.md).
5. Atualize e use fontes oficiais para aplicativos após o primeiro boot.
