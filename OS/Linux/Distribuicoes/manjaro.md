# Manjaro

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Arch, com repositórios e política próprios |
| Filosofia | Tornar experiência Arch-like mais acessível por instalador/ferramentas gráficas |
| Lançamento | Rolling, com camadas/testes próprios antes de alguns pacotes chegarem ao usuário |
| Dificuldade | 🟡 |
| Pacotes | Pacman e ferramentas do projeto |

## Para que serve

Manjaro é uma opção para quem quer desktop Arch-like com instalador visual e ambientes prontos. Ainda exige respeito ao modelo rolling e à documentação específica do Manjaro.

## Pontos positivos

- instalador e ferramentas gráficas;
- múltiplos desktops disponíveis;
- ecossistema Arch/Pacman com abordagem própria de entrega.

## Pontos de atenção

- não use instrução de Arch sem confirmar compatibilidade com repositórios Manjaro;
- pacotes comunitários exigem revisão e entendimento;
- rolling release não é “instalar e esquecer”.

## Para quem recomendo / não recomendo

**Recomendo** para usuário com alguma base que quer Arch-like mais guiado.  
**Não recomendo** para servidor crítico, iniciante que não pretende aprender manutenção ou quem precisa de suporte empresarial específico.

## Requisitos, desktop e pacotes

Consulte [Manjaro](https://manjaro.org/) para edições, requisitos e downloads atuais. Use Pacman/atualizador conforme documentação Manjaro.

## Instalação específica

1. Baixe apenas a edição oficial (KDE, GNOME, Xfce ou outra disponível).
2. Teste live USB e confirme Wi‑Fi/GPU.
3. Em dual boot, preserve EFI/Windows e use espaço não alocado.
4. Após instalar, atualize pelo fluxo Manjaro; não misture espelhos/configurações de Arch sem entender consequências.
5. Leia notícias/avisos do projeto antes de atualizações grandes.
