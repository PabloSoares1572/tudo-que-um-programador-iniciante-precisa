# Pop!_OS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Ecossistema System76, historicamente baseado em Ubuntu; confirme base da versão atual |
| Filosofia | Desktop para criadores, desenvolvimento e hardware, com foco em fluxo de trabalho |
| Dificuldade | 🟢/🟡 |
| Pacotes | Ecossistema `.deb`/APT e formatos de desktop conforme versão |

## Para que serve

Pop!_OS é voltado a desktop, desenvolvimento e algumas configurações de GPU. O projeto tem identidade própria de desktop e integração com hardware System76; isso não significa que será automaticamente a melhor escolha para qualquer PC.

## Pontos positivos

- foco em produtividade e desktop;
- documentação/ferramentas do projeto;
- pode ser atraente para quem usa notebooks e GPUs compatíveis.

## Pontos de atenção

- escolhas de desktop/base mudam entre gerações; leia documentação da release atual;
- nem todo hardware ou jogo terá comportamento idêntico;
- não é substituto automático de Ubuntu Server/RHEL em produção.

## Para quem recomendo / não recomendo

**Recomendo** para desktop e desenvolvimento quando você gosta do fluxo do projeto e confirma compatibilidade.  
**Não recomendo** para quem quer máxima estabilidade de servidor, um sistema muito leve ou primeiro contato sem testar live USB.

## Requisitos, desktop e pacotes

Consulte [Pop!_OS/System76](https://system76.com/pop) para ISO, hardware e documentação atuais. Confira a versão/edição correta para GPU e arquitetura na própria página; não baixe imagem de espelhos aleatórios.

## Instalação específica

1. Use o download oficial e leia notas de instalação da versão atual.
2. Faça live boot, testando Wi‑Fi, suspensão, monitor e GPU.
3. Em notebook com GPU dedicada, leia primeiro instruções oficiais de driver/energia.
4. Use espaço não alocado no dual boot e preserve a partição EFI existente quando o instalador orientar.
5. Atualize o sistema pelo mecanismo oficial após iniciar.
