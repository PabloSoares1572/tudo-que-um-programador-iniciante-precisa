## Para que serve

Solus é uma opção desktop independente, conhecida por ambientes próprios/opções de desktop e foco em usuário final. Como não é Debian/Fedora/Arch, instruções de pacotes de outras famílias não se aplicam.

## Pontos positivos

- foco em desktop coeso;
- projeto independente, com decisões próprias;
- pode ser boa opção para quem quer experimentar outro ecossistema.

## Pontos de atenção

- repositório/ecossistema menor que famílias gigantes;
- disponibilidade de software/driver deve ser conferida antes de migrar;
- documentação/comandos são específicos do projeto.

## Para quem recomendo / não recomendo

**Recomendo** para desktop pessoal após testar aplicativos e hardware.  
**Não recomendo** para ambiente onde você depende de instrução/certificação de Debian/RHEL ou primeiro Linux sem testar compatibilidade.

## Requisitos, desktop e pacotes

Veja [Solus](https://getsol.us/) para imagens, ambientes e requisitos atuais. O gerenciador de pacotes é eopkg; use repositórios oficiais.

## Instalação específica

1. Baixe ISO pelo site oficial.
2. Teste live USB, Wi‑Fi, áudio, GPU e software essencial.
3. Em dual boot, siga espaço não alocado e preserve EFI/Windows.
4. Após iniciar, atualize pelo método Solus e aprenda eopkg antes de seguir guias de outras distros.
