# Zorin OS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Ubuntu |
| Filosofia | Transição acessível de Windows/macOS para Linux |
| Dificuldade | 🟢 Iniciante |
| Pacotes | APT/`.deb` e formatos integrados conforme configuração |

## Para que serve

Zorin OS é focado em desktop/notebook, interface familiar e experiência simples. Pode ser boa escolha para quem está migrando de Windows e quer aprender sem começar pelo terminal.

## Pontos positivos

- instalação guiada e documentação amigável;
- foco em aparência/usabilidade de desktop;
- edições e ferramentas voltadas a diferentes perfis de hardware/usuário.

## Pontos de atenção

- compare edição gratuita/paga e requisitos no site oficial;
- “parecido com Windows” não significa compatibilidade nativa com todo programa Windows;
- para PC muito antigo, confirme se a edição leve está disponível e suportada.

## Para quem recomendo / não recomendo

**Recomendo** para iniciantes e pessoas que querem desktop Linux visualmente familiar.  
**Não recomendo** para quem busca laboratório de administração avançada, servidor ou rolling release.

## Requisitos, desktop e pacotes

Veja [Zorin OS](https://zorin.com/os/) e os [requisitos oficiais](https://help.zorin.com/docs/getting-started/). O projeto documenta instalações ao lado ou no lugar do sistema existente; ainda assim, backup é obrigatório.

## Instalação específica

1. Baixe pelo [site oficial](https://zorin.com/os/download/).
2. Siga [Como instalar Zorin OS](https://help.zorin.com/docs/getting-started/install-zorin-os/).
3. Teste modo live antes de tocar no disco.
4. Para dual boot, leia [Dual boot](../../DUAL-BOOT.md), faça espaço não alocado e confira a tela de resumo do instalador.
5. Após instalar, use atualizador/loja oficial e confira drivers de GPU.
