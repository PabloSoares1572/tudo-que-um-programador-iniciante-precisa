# openSUSE Tumbleweed

| Pacotes | RPM, Zypper e YaST |

## Para que serve

Tumbleweed é para desktop/desenvolvimento com software mais atual, sem deixar de usar ferramentas openSUSE. Requer rotina de atualização e leitura de avisos, como qualquer rolling release.

## Pontos positivos

- software e kernel atuais;
- ferramentas YaST/Zypper;
- boas opções de desktops e snapshots em instalações compatíveis.

## Pontos de atenção

- atualização contínua pede manutenção e espaço/backup;
- snapshot não é backup externo;
- não use procedimento de Leap como se fosse igual.

## Para quem recomendo / não recomendo

**Recomendo** para usuário intermediário, desenvolvimento e quem aceita rolling release.  
**Não recomendo** para servidor crítico sem política de atualização/teste ou usuário que não quer acompanhar mudanças.

## Requisitos, desktop e pacotes

Use [openSUSE Tumbleweed](https://get.opensuse.org/tumbleweed/) para imagem e requisitos atuais. Pacotes são RPM via Zypper.

## Instalação específica

1. Baixe ISO oficial e verifique integridade conforme instrução atual.
2. Teste GPU, rede e hardware antes de instalar.
3. Considere snapshots somente entendendo uso de disco e recuperação.
4. Em dual boot, não modifique ESP/Windows sem backup.
5. Atualize pelo fluxo Tumbleweed e revise mudanças relevantes antes de aceitar grandes atualizações.
