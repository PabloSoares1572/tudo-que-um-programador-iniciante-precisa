# antiX

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Debian |
| Filosofia | Sistema leve para hardware modesto, com escolhas próprias de init/desktop |
| Dificuldade | 🟡 |
| Pacotes | APT/`.deb` |

## Para que serve

antiX é focado em computadores com poucos recursos e usuários que aceitam interface/fluxo mais enxuto. Pode revitalizar máquina antiga, mas não resolve limitações físicas, drivers sem suporte ou navegador pesado.

## Pontos positivos

- foco em baixo consumo;
- base Debian e APT;
- opções enxutas para PCs antigos.

## Pontos de atenção

- experiência pode ser menos familiar para iniciante;
- não confunda leveza com suporte garantido a todo hardware/aplicativo;
- algumas escolhas de sistema diferem do padrão systemd de outras distros.

## Para quem recomendo / não recomendo

**Recomendo** para PC antigo e usuário disposto a aprender ambiente leve.  
**Não recomendo** para quem quer visual moderno completo, jogos atuais ou primeiro Linux sem testar live USB.

## Requisitos, desktop e pacotes

Consulte [antiX](https://antixlinux.com/) para imagens, arquitetura e requisitos atuais. A base usa APT; siga documentação própria para serviços/init.

## Instalação específica

1. Teste live USB antes de apagar sistema atual.
2. Use ISO e verificação do projeto oficial.
3. Escolha ambiente/edição adequada ao hardware.
4. Em dual boot, trate particionamento com o mesmo cuidado de qualquer Debian.
5. Após instalar, atualize e teste áudio, rede e suspensão no hardware real.
