# Kali Linux

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Debian |
| Filosofia | Distribuição voltada a testes de segurança autorizados e laboratório |
| Dificuldade | 🔴 Avançado como sistema principal |
| Pacotes | APT/`.deb` e repositórios próprios |

## Para que serve

Kali reúne ferramentas de segurança para profissionais, estudantes e laboratórios autorizados. Não é “Linux mais seguro” nem melhor para uso diário; ter ferramentas ofensivas instaladas não substitui conhecimento, autorização ou boas práticas.

## Pontos positivos

- ferramentas e documentação para segurança;
- base conhecida e ambiente de laboratório;
- útil para cursos, CTFs e testes com escopo permitido.

## Pontos de atenção

- usar como desktop diário aumenta complexidade desnecessária para iniciante;
- ferramentas podem causar dano/alertas se usadas fora de laboratório;
- não use contra redes, sistemas ou pessoas sem autorização explícita.

## Para quem recomendo / não recomendo

**Recomendo** para laboratório, aprendizado formal e pentest autorizado.  
**Não recomendo** como primeira distro, “antivírus”, sistema para jogos ou forma de invadir Wi‑Fi/contas.

## Requisitos, desktop e pacotes

Use somente [Kali oficial](https://www.kali.org/get-kali/). A distribuição oferece diferentes imagens/ambientes; escolha pelo cenário documentado e verifique hashes/assinaturas conforme o projeto.

## Instalação específica

1. Prefira máquina virtual ou live USB persistente para aprendizado inicial.
2. Baixe ISO/VM pelo canal oficial e valide arquivo.
3. Não instale ferramentas em computador de trabalho sem autorização.
4. Para dual boot, trate como qualquer distro Debian, mas questione primeiro se VM não é mais segura.
5. Use apenas alvos próprios/autorizados e mantenha logs/escopo de laboratório.
