# Red Hat Enterprise Linux (RHEL)

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Red Hat Enterprise Linux |
| Filosofia | Plataforma empresarial com suporte, certificações e ciclo planejado |
| Dificuldade | 🟡 para administração; não é foco de desktop doméstico |
| Pacotes | RPM/DNF |

## Para que serve

RHEL é voltado a servidores, nuvem, empresas, aplicativos certificados e ambientes que valorizam ciclo de vida, suporte e processos de mudança. Uso/licenciamento dependem de oferta/contrato Red Hat.

## Pontos positivos

- suporte e ecossistema empresarial;
- foco em estabilidade, segurança e certificações;
- documentação forte para administração.

## Pontos de atenção

- não é escolha comum para PC gamer/doméstico;
- assinatura, repositórios e suporte têm regras próprias;
- versões de software podem ser deliberadamente conservadoras.

## Para quem recomendo / não recomendo

**Recomendo** para carreira de sysadmin, laboratório empresarial e ambientes que usam Red Hat.  
**Não recomendo** para primeiro Linux desktop ou quem quer instalar sem considerar licenciamento/suporte.

## Requisitos, desktop e pacotes

Consulte [RHEL](https://www.redhat.com/en/technologies/linux-platforms/enterprise-linux) e documentação/redes de assinatura oficiais. Use DNF/RPM conforme a versão e política do ambiente.

## Instalação específica

1. Obtenha mídia apenas por portal/canal oficial autorizado.
2. Defina objetivo: servidor, VM, laboratório ou workstation.
3. Planeje assinatura, repositórios, rede, usuário administrativo e atualizações antes de produção.
4. Para laboratório, use VM e siga guia da versão correta.
5. Não habilite repositórios de terceiros em servidor empresarial sem aprovação/compatibilidade.
