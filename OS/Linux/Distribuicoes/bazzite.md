# Bazzite

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Ecossistema Fedora Atomic/Universal Blue |
| Filosofia | Experiência de jogos e desktop imutável em hardware compatível |
| Dificuldade | 🟡 |
| Pacotes | Base atômica, Flatpak/containers e mecanismos próprios do projeto |

## Para que serve

Bazzite é orientado a jogos, Steam e dispositivos/PCs compatíveis. Pode ser uma opção atraente para biblioteca Steam, mas compatibilidade de cada jogo (especialmente anti-cheat) precisa ser verificada antes de trocar de sistema.

## Pontos positivos

- foco explícito em experiência gamer;
- modelo atômico/rollback herdado do ecossistema;
- imagens/variantes voltadas a cenários específicos do projeto.

## Pontos de atenção

- não é Fedora Workstation tradicional;
- administração, pacotes e modificações seguem modelo atômico;
- não prometa compatibilidade universal com jogos Windows, launchers ou anti-cheat.

## Para quem recomendo / não recomendo

**Recomendo** para jogador que testou os jogos principais e aceita modelo imutável.  
**Não recomendo** para servidor, PC de trabalho crítico sem teste ou usuário que precisa fazer alterações profundas no sistema diariamente.

## Requisitos, desktop e pacotes

Use [Bazzite oficial](https://bazzite.gg/) para escolher imagem, dispositivo, GPU e método de instalação. Leia compatibilidade de hardware/jogos e instruções atuais antes de gravar pendrive.

## Instalação específica

1. Escolha a imagem exatamente para seu dispositivo/desktop/GPU conforme site oficial.
2. Teste por live USB quando a imagem oferecer essa possibilidade.
3. Mantenha Windows em dual boot até validar seus jogos mais importantes.
4. Após instalar, aprenda atualização/rollback e Flatpak antes de adicionar camadas na base.
5. Não misture guias de pacotes tradicionais sem conferir documentação Bazzite.
