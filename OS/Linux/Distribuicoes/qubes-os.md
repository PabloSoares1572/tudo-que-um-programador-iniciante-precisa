# Qubes OS

## Visão geral

| Item | Descrição |
| --- | --- |
| Família/base | Sistema especializado em compartimentalização por virtualização |
| Filosofia | Segurança por isolamento de domínios/VMs para tarefas diferentes |
| Dificuldade | 🔴 |
| Pacotes | Dependem de domínios/template; não é desktop Linux comum |

## Para que serve

Qubes OS separa atividades em domínios para reduzir impacto de comprometimento. Exige hardware compatível, boa quantidade de recursos e compreensão do modelo. Não é indicação automática para qualquer notebook nem solução contra todos os riscos.

## Pontos positivos

- foco em isolamento e segurança;
- documentação oficial de verificação/instalação;
- bom material para quem estuda modelo de ameaça e compartmentalization.

## Pontos de atenção

- requisitos de hardware/virtualização são importantes;
- curva de aprendizagem alta;
- pode não ser adequado para jogos, hardware limitado ou uso sem tempo de estudo.

## Para quem recomendo / não recomendo

**Recomendo** para usuário avançado com necessidade real de compartimentalização e hardware suportado.  
**Não recomendo** como primeiro Linux, PC de jogos, computador fraco ou substituto de backup/boas práticas.

## Requisitos, desktop e pacotes

Comece por [Qubes OS](https://www.qubes-os.org/), [downloads](https://www.qubes-os.org/downloads/) e [guia de instalação](https://doc.qubes-os.org/en/latest/user/downloading-installing-upgrading/installation-guide.html). Verifique ISO/assinaturas conforme instrução oficial.

## Instalação específica

1. Leia requisitos de virtualização/compatibilidade antes de comprar/formatar hardware.
2. Use computador confiável para baixar/validar a ISO, conforme guia.
3. Faça backup externo; a instalação altera disco.
4. Não trate dual boot como caminho padrão sem avaliar segurança/complexidade.
5. Após instalar, aprenda domínios, templates, atualizações e backups antes de colocar dados sensíveis.
