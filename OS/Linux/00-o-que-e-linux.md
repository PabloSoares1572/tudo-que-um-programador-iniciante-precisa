# 00 — O que é Linux?

## Explicação simples

Linux é o núcleo (kernel) que permite que o sistema operacional converse com processador, memória, disco, rede e periféricos. Uma distribuição junta esse kernel com instalador, programas, repositórios, ambiente gráfico e decisões de configuração para entregar um sistema utilizável.

## Linux, GNU/Linux e distribuição

| Termo | Significado |
| --- | --- |
| Kernel Linux | Parte central que gerencia hardware e recursos |
| GNU/Linux | Nome usado quando se destaca a união do kernel com ferramentas GNU e outros componentes |
| Distribuição (distro) | Sistema completo montado por projeto/empresa/comunidade, como Debian, Fedora ou Arch |
| Ambiente gráfico (DE) | Interface visual: GNOME, KDE Plasma, Xfce, Cinnamon etc. |
| Shell | Programa que interpreta comandos, como Bash |
| Terminal | Aplicativo que abre uma sessão para o shell |
| Root | Conta administrativa máxima |
| sudo | Forma controlada de executar uma ação administrativa |

## História resumida

Unix influenciou muitos sistemas. O kernel Linux surgiu em 1991; ferramentas livres e comunidades ajudaram a formar sistemas completos. Hoje Linux está em servidores, nuvem, supercomputadores, roteadores, Android, notebooks, desktops, dispositivos embarcados e plataformas de desenvolvimento.

## O que muda entre distribuições

- instalador e configuração inicial;
- ciclo de lançamento e estabilidade;
- gerenciador de pacotes e repositórios;
- ambiente gráfico padrão;
- foco: desktop, servidor, privacidade, jogos, aprendizagem ou minimalismo;
- ferramentas próprias e suporte comercial/comunitário.

Elas compartilham muitos conceitos, mas comandos de pacote, versões e decisões de segurança podem variar. Não copie um tutorial de Arch para Ubuntu, ou vice-versa, sem adaptar.

## O que Linux não é

- Não é automaticamente mais rápido em qualquer hardware.
- Não é invulnerável a malware ou erro humano.
- Não exige terminal para tarefas básicas, mas saber terminal aumenta autonomia.
- Não é uma única interface; GNOME, KDE e Xfce podem parecer sistemas diferentes.

Instale uma distribuição em máquina virtual ou use Live USB. Abra o menu de aplicativos, abra um terminal e execute `pwd`. Não precisa entender tudo agora; o próximo capítulo explica os primeiros passos.
